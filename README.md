# 回声

每 6 秒一轮，收集金星。一轮结束后，你刚才走过的路线会变成回声幽灵，在下一轮原样重放。碰到任何一个过去的自己，游戏结束。

用浏览器打开 `index.html` 即可游玩。鼠标或触摸跟随，也可以用 WASD / 方向键移动。点击、触摸或按空格开始。没有服务器时，这一页一直是单机。

## 多人

同一块 960×540 的场地上一起走。回声路线、换轮前的提示，以及每轮开头 60 步的保护，都跟服务器走。

```bash
npm install
npm start
```

浏览器开两个窗口，都打开 http://127.0.0.1:8787/ ，各自点「多人同场」。人数变成 2 以后，任一窗口按空格或再点按钮开始。分房用 `?room=房间名`，指定名字用 `?name=甲`。

保护期由服务器判定：场上已经有回声时，每轮前 60 步不结算碰撞。这段时间回声按同一个步号闪烁（每 2 步在 50% 和 15% 之间），脚底 4px 的圆是虚线，保护结束后换成实线。碰到任何一条已经成形的回声都会死，活着的玩家互相穿过。一个人死了，其他人继续；全部倒下后可以重开。

## 装备

货币是 T 币。吃一颗金星 +4T，活过一轮 +8T。金星分和过轮分仍按原来的 10×轮数 和 +50 计算，幸运草会把这两笔分数乘上去。每轮结束进入 8 秒商店，可以买、升级、换装。全员点「准备好了」会在 1.5 秒后提前开始。轮中不能换。头、身、饰品各一槽，背包 6 格。买到空槽会直接穿上。升级最多 3 级。

| 装备 | 槽 | 购买 | 2 级 | 3 级 | 效果 |
| --- | --- | --- | --- | --- | --- |
| 轻风靴 | 身 | 8T | 16T | 24T | 移速 ×1.18 / ×1.36 / ×1.55 |
| 回声护盾 | 饰品 | 15T | 30T | 45T | 每轮抵挡 1 / 2 / 3 次回声，然后才扣血 |
| 淡影眼镜 | 头 | 12T | 24T | 36T | 回声落点提示从轮末 1.25 秒提前到 2.2 / 3.2 / 4.2 秒 |
| 星星磁铁 | 饰品 | 10T | 20T | 30T | 拾取 ×1.8 / ×2.5 / ×3.4，并在 90 / 140 / 200px 内把星吸过来 |
| 冲刺手套 | 身 | 12T | 24T | 36T | Shift 冲刺 8 / 10 / 12 步，速度 ×2.6 / ×3.0 / ×3.4，冷却 3.0 / 2.0 / 1.2 秒 |
| 铁头盔 | 头 | 10T | 20T | 30T | 最大生命 2 / 3 / 4。基础是 1 点，受击后 0.6 秒无敌 |
| 幸运草 | 饰品 | 14T | 28T | 42T | 金星分和过轮分 ×1.5 / ×2 / ×3 |

同槽只能穿一件。护盾先于生命结算。多人时这些状态在服务器上，别人名字旁能看到你穿的图标。单机不连服务器也有同一套商店。T 币和装备每局清空，不跨局保存。
